Turkish. JSON Patch guards and replacements, a translation ledger, a build/check
tool and installation documentation have been added. The ASCII variant further
transliterates only the Turkish display text. No original gameplay logic was
copied or modified by this patch. Original English text excerpts are retained
for source matching and attribution.
