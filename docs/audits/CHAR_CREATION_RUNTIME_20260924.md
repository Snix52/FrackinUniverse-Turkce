# Karakter oluşturma — 24 Eylül 2026

v0.63.1'de karakter oluşturma ekranındaki 19 alanı birden atlayan yama düzeltildi. FU'nun değiştirdiği zorlu mod açıklaması kaynakla eşleştirildi; alanlar bağımsız koşullu yama gruplarına ayrıldı.

Steam FU dosyalarındaki CRLF ile Git kaynağındaki LF farkı, Avian dahil 10 çok satırlı tür açıklamasını etkiliyordu. Aynı metnin iki satır sonu biçimi desteklendi.

Oyuncu ekranında “IRK” başlığı ve Avian/Fenerox/Thelusian açıklamaları Türkçe görüldü. Kısaltılan zorlu mod açıklaması 800×630 pencerede sığdı. Görsele gömülü İngilizce başlık ve katalog dışındaki türe özel etiketler ayrı kaldı.
