build_validate.py
  Python 3.9+ standart kütüphanesiyle patch üretir.
  Jeoloji + Tarım + Kimya + Mühendislik + Güç Sistemleri + Zanaatkârlık + Zırh ve Silahlar + Delilik + tutorial görev/hedef + bağlı görev/makine/kaynak allowlist'lerini doğrular.
  Ham Lua çevirilerinde beklenen kaynak kod parçalarını exact-match sayısıyla doğrular.
  ASCII sürüm üretmez.
  Pinned FU 6.5.8 kaynağında aktif researchTree düğümüne bağlı olmayan bilinen araştırma stringlerini reddeder.

Yeni çıktı:
  python build_validate.py --output yeni_cikti

Açılmış FU kaynaklarıyla tam doğrulama:
  python build_validate.py --source-dir "D:\FU_acilmis" --output dogrulanmis_cikti
