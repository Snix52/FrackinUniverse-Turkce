build_validate.py
  Python 3.9+ standart kütüphanesiyle patch üretir.
  Jeoloji + Tarım + Kimya + Mühendislik + Güç Sistemleri + Zanaatkârlık + Zırh ve Silahlar + Delilik + erişilebilir görev/hedefler + v0.17 üretim makineleri + v0.18 işlevsel nesneler + v0.19 üretim malzemeleri + v0.20 aktif özel görevler + v0.21 erken oyun silahları + v0.22 Kademe 3 savaş ekipmanı/Usta Manipülatör tutarlılığı + v0.23-v0.24 Kademe 4 savaş ekipmanı + v0.25-v0.29 Kademe 1-5 aktif zırh setleri + v0.28 Kademe 5 savaş ekipmanı + v0.30 kalan aktif araştırma ekipmanı allowlist/deny-guard kapsamını doğrular.
  Ham Lua çevirilerinde beklenen kaynak kod parçalarını exact-match sayısıyla doğrular.
  ASCII sürüm üretmez.
  Pinned FU 6.5.8 kaynağında aktif researchTree düğümüne bağlı olmayan bilinen araştırma stringlerini reddeder.

Yeni çıktı:
  python build_validate.py --output yeni_cikti

Açılmış FU kaynaklarıyla tam doğrulama:
  python build_validate.py --source-dir "D:\FU_acilmis" --output dogrulanmis_cikti

Ana GitHub Actions build'i `tools/kaynaklar.json` içindeki pinned FU commitini otomatik checkout eder ve `--source-dir` ile tam kaynak doğrulamasını zorunlu çalıştırır. Aynı `build_output`, hem repository'deki `FU_Turkce/` kurulum ağacına hem de `dist` ZIP paketine kaynak olur.
