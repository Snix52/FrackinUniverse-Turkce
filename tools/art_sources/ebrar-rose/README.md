# Ebrar rose source art

The user requested the Little Prince's rose in a glass bell jar with sparkles,
replacing the former star lamp. The original transparent PNG was generated with
the built-in Imagegen tool on 2026-09-26. It is original generated art inspired
by that idea, not artwork extracted from the book or another mod.

Prompt: A single front-view Starbound-style pixel-art red rose under a clear
glass bell jar, curved green stem with two leaves, pale cyan reflections,
dark bronze/copper base with brass accents, transparent background. Delicate
shading, crisp pixels, no text or large glow, two small glass glints; surrounding
sparkles are animated by the game. The requested logical canvas was 32×32;
the actual generated PNG is 1254×1254, so export explicitly crops the object
and uses nearest-neighbor sampling.

`../../prepare_ebrar_rose_art.ps1` exports the cropped source as 24×40 object art
and a centered 16×16 inventory icon. The legacy item ID and image filenames are
retained so existing saves and crafted items adopt the new appearance. There is
no opaque fullbright overlay: it used to obscure the old sprite's shading.
